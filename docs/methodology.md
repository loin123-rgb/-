# 分析方法論說明

> 本文件說明「國際情勢投資分析框架」背後的研究邏輯與分析方法。

---

## 一、框架設計理念

本框架基於以下核心觀念設計：

1. **Top-Down 分析**：由宏觀國際情勢出發，逐層向下到產業供需、商品價格，最終落地到個股投資決策。

2. **供需為價格之根**：商品價格長期由供需決定，國際事件是干擾短期供需平衡的主要催化劑。

3. **期貨市場先行**：期貨市場的持倉結構（COT）與曲線形態（Contango/Backwardation）往往能預示現貨價格走向。

4. **個股連結商品**：商品相關個股的股價表現高度依賴對應商品的價格走勢，透過量化相關性驗證這種關聯。

---

## 二、分析流程架構

### 第一層：國際事件掃描

監控以下類型事件對商品供需的衝擊：

| 事件類型 | 對供給側影響 | 對需求側影響 | 主要相關商品 |
|---------|------------|------------|------------|
| 地緣衝突（戰爭/制裁） | 減少（封鎖產區） | 不確定 | 能源、小麥、金屬 |
| 貨幣/財政政策 | 間接 | 影響整體需求 | 黃金、工業金屬 |
| 氣候異常（El Niño/La Niña） | 農業減產 | 不變 | 小麥、玉米、大豆 |
| 主要國家政策（OPEC+/減碳） | 直接 | 中長期影響 | 能源、新能源金屬 |
| 經濟衰退/復甦 | 資本支出下滑 | 直接影響 | 銅、鐵礦石、原油 |

### 第二層：供需動態評估

使用以下數據源進行定量分析：

- **能源**：EIA（美國能源資訊局）、IEA（國際能源署）、OPEC 月報
- **金屬**：LME（倫敦金屬交易所）庫存、礦業公司產量報告
- **農產品**：USDA WASDE（世界農業供需估計）、主產國農業部數據
- **宏觀**：IMF/世界銀行 GDP 預測、PMI 製造業數據

**供需缺口計算**：

```
供需缺口 = 全球供給量 - 全球需求量
正缺口（過剩）→ 庫存累積 → 價格承壓
負缺口（短缺）→ 庫存下降 → 價格上行
```

### 第三層：價格與期貨分析

**期貨曲線形態解讀**：

| 形態 | 特徵 | 市場信號 | 交易啟示 |
|------|------|----------|----------|
| Backwardation（現貨溢價） | 近月價 > 遠月價 | 近期供給緊張 | 做多近月，賣遠月 |
| Contango（期貨溢價） | 遠月價 > 近月價 | 供給充裕或儲存成本 | 避免持有現貨/ETF（滾倉損耗） |
| 平水 | 近遠月接近 | 市場均衡預期 | 中性 |

**COT 持倉分析框架**：

```
管理資金（Managed Money）= 趨勢追蹤者
  → 淨多頭 > 90%百分位：過度樂觀，注意回調
  → 淨多頭 < 10%百分位：過度悲觀，關注反彈

商業商（Commercials/Hedgers）= 聰明錢
  → 商業商增加淨多頭 + 管理資金增加淨空頭 → 潛在反轉向上
  → 商業商增加淨空頭 + 管理資金增加淨多頭 → 潛在反轉向下
```

### 第四層：個股篩選與評估

**篩選標準**：

1. **直接暴露度**：公司收入/獲利對目標商品的依賴程度
2. **成本結構**：是否為低成本生產者（危機中更具韌性）
3. **財務健康度**：負債率、現金流品質
4. **估值相對歷史**：是否已反映商品價格預期
5. **催化劑時間表**：近期是否有加速估值重估的事件

**商品-個股相關性驗證**：

使用 `analyze_correlation.py` 計算 60/90 日滾動相關係數，篩選相關係數 > 0.6 的配對作為可信的對應關係。

## 三、情境分析方法

對每次重大事件，構建三種情境：

| 情境 | 假設 | 機率 | 商品價格影響 | 個股影響 |
|------|------|------|------------|--------|
| 樂觀（Bull Case） | 事件緩解或比預期輕 | X% | +___% | |
| 基準（Base Case） | 市場主流預期實現 | X% | ___% | |
| 悲觀（Bear Case） | 事件惡化或超預期 | X% | -___% | |

**加權期望報酬**：
```
期望報酬 = (樂觀機率 × 樂觀報酬) + (基準機率 × 基準報酬) + (悲觀機率 × 悲觀報酬)
```

## 四、更新頻率建議

| 分析類型 | 更新頻率 | 觸發條件 |
|----------|----------|----------|
| 事件分析 | 事件驅動 | 重大國際事件發生時 |
| 供需動態 | 每月 | USDA WASDE、EIA月報後 |
| 商品價格追蹤 | 每週 | 每週一更新 |
| 期貨走勢分析 | 每週 | COT報告發布後（週五） |
| 個股分析 | 每季 | 季報發布後 |
| 綜合投資報告 | 每月 | 月底彙整 |

## 六、已知限制與注意事項

1. **資料延遲**：Yahoo Finance 免費資料存在 15 分鐘延遲，不適合即時交易決策
2. **COT 資料滯後**：CFTC COT 報告反映週二數據，週五才公布，存在 3 個交易日滯後
3. **相關性不穩定**：商品與個股的相關性在市場壓力期可能改變，需定期重新計算
4. **分析非投資建議**：本框架輸出的分析僅供研究參考，不構成具體投資建議
